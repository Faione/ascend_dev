MXFP8 Add Pipeline

沿用 原始 Add Pipeline 的 GM → UB → Add → GM 内核，在调用它之前加入逐组量化与反量化。量化由 PyTorch 张量操作执行；原始 AI Core Add 内核仍计算 FP32。

一组 32 个元素怎样流动

① FP32 输入x、y 各是一维连续张量
② 逐组求 scale每 32 个元素取最大绝对值，求 2 的幂并编码为 E8M0
③ 量化为 E4M3FN值除以各组 scale，再舍入为 FP8
④ 反量化FP8 值乘回对应 scale，形成 FP32 输入
⑤ Add Pipeline原始内核逐 tile 搬运、相加、回写 FP32

对应代码

# examples/add_pipeline/mxfp8_add_pipeline.py
x8, sx = quantize_mxfp8(x)
y8, sy = quantize_mxfp8(y)
dx = dequantize_mxfp8(x8, sx)
dy = dequantize_mxfp8(y8, sy)
z = torch.ops.ascend_add_pipeline.add_pipeline(dx, dy)

CPU 演示：python examples/add_pipeline/mxfp8_add_pipeline.py。NPU 上导入 ascend_add_pipeline 后，将其算子传给 mxfp8_add_pipeline(x, y, add=torch.ops.ascend_add_pipeline.add_pipeline)。

输出是 FP32。若输出也需要 MXFP8，还须对加法结果重新量化并返回新的 E8M0 scale。此例展示输入量化造成的误差，不代表原始 Add 内核执行 FP8 运算。
